Task 6: Create a Strong Password and Evaluate Its Strength

Objective:
To understand the factors that make a password strong and to test different passwords using an online password strength checker.

Tools Used:
Password Strength Checker: https://www.passwordmeter.com

1. First Password: password123 - lowercase + numbers.
2. Second Password: Password@123 - uppercase + lowercase + numbers + symbol
3. Third Password: P@55w0rd! - mixed case + numbers + symbol
4. Fourth Password: Qw!7zT$Lp#9m - mixed case + numbers + multiple symbols

Best Practices for Creating Strong Passwords:

1. Use atleast 12-16 characters.
2. Mix randomly with uppercase, lowercase, numbers, symbols.
3. Avoid common words, personal names or predictable sequence.
4. Never reuse the same passwords across multiple accounts.
5. Consider using a password manager to manage complex passwords.

Tips learned from Evaluation:

1. Increasing the length of the password increases the strength.
2. Adding multiple symbols and using mixed case of alphabets makes brute force harder.
3. Random uncommon variation of words is better than combination of common sequence of words
4. Common mix like "P@ssw0rd" are still weak against advanced cracking tools.

Common Password Attacks:

1. Brute Force Attack: 

-> It tries all possible combinations until the correct one is found.
-> If the password is short and simple they are easy to find the through brute force.

2. Dictionary Attack:

-> It uses a list of common words and known password pattern to guess passwords quickly.

Complexity affects security:

1. Short passwords that are under 8 characters can be cracked in seconds by brute force.
2. Long and random passwords exponentially increase cracking time.
3. Adding multiple character type prevents dictionary-based and pattern-based attacks.
4. Complexity makes automated guessing tools inefficient, forcing attackers to require far more time and resources.
